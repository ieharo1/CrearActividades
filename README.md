# CrearActividades

Proyecto para crear y gestionar actividades académicas o laborales.

## Descripción

Aplicación que permite crear, organizar y gestionar diferentes tipos de actividades.

## Características

- Creación de actividades
- Gestión de fechas y recordatorios
- Organización por categorías

## Stack Tecnológico

- HTML/CSS/JavaScript
- Base de datos local

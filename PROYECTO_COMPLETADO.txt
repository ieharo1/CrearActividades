📊 ENDPOINTS IMPLEMENTADOS:

   USUARIOS (CRUD):
   POST   /api/users           → Crear usuario
   GET    /api/users/{id}      → Obtener usuario
   GET    /api/users           → Listar todos
   PUT    /api/users/{id}      → Actualizar
   DELETE /api/users/{id}      → Eliminar

   CARPETAS (CRUD):
   POST   /api/folders              → Crear carpeta
   GET    /api/folders/{id}         → Obtener carpeta
   GET    /api/folders/user/{uid}   → Listar mis carpetas
   PUT    /api/folders/{id}         → Actualizar
   DELETE /api/folders/{id}         → Eliminar

   ARCHIVOS (CRUD):
   POST   /api/files/upload         → Subir archivo
   GET    /api/files/{id}           → Obtener detalles
   GET    /api/files/folder/{fid}   → Listar archivos
   GET    /api/files/search         → Búsqueda avanzada
   PUT    /api/files/{id}           → Actualizar
   GET    /api/files/{id}/download  → Descargar
   DELETE /api/files/{id}           → Eliminar
